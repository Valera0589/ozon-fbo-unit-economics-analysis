## 📥 Исходные данные
- Артикул и закупочная цена товаров — предоставлены в тестовом задании
- Розничная цена — предоставлена в тестовом задании
- Затраты на Ozon FBO — рассчитаны самостоятельно через 
  [официальный калькулятор Ozon для селлеров](https://seller-edu.ozon.ru/docs/uchebnik/tarify-tsi-fbo.html)

## 🛠 Методология расчета
1. Загрузил артикулы и закупочные цены из ТЗ
2. Для каждого товара рассчитал затраты на FBO через калькулятор Ozon 
   (учтены: комиссия категории, логистика до склада, хранение, последняя миля)
3. Рассчитал юнит-экономику:
   - Валовая прибыль = Розничная цена - Закупочная цена
   - Чистая прибыль = Валовая прибыль - Затраты на FBO
   - Маржа = Чистая прибыль / Розничная цена
   - ROI = Чистая прибыль / Закупочная цена
